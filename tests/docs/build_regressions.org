#+title: Image build regression checks
#+description: Checks for variant selection and build command generation
#+authors: Immutablue contributors

* Variant selection
Run =bash tests/test_build_variants.sh=, requiring Fedora packages =bash= and =make=. These checks evaluate the actual Make variable definitions without building an image.

Nucleus and workshop builds remove GUI and desktop-specific flags. Distroless and Bazzite replace the selected desktop with their own flags. Independent add-ons are retained as separate CSV entries, including when an explicit desktop flag was supplied. This keeps package selection and exact runtime variant checks consistent with the base image.

* Target architecture
Run =bash tests/test_build_platform.sh=. It dry-runs the real Makefile with AMD64 and ARM64 selections for the normal image, distroless image and dependency container. Generated prerequisites are skipped, so no build context or container storage is changed.

Both main image engines receive =--platform $(PLATFORM)=, matching the dependency build. =make PLATFORM=linux/arm64 build= therefore explicitly requests ARM64 instead of relying on the engine's native architecture. Actual cross-architecture execution still requires suitable emulation and upstream images for that architecture; this check verifies command generation, not an image boot.

* Running the focused suite
=make test_regressions= runs all build and bootstrap regression checks without building an image. The full =make test= (also available as =make tests=) includes these checks alongside the existing container, artifact and setup tests.
